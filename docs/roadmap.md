# Clonalyst roadmap (first 15 months)

| Months | Milestone | Done when |
| --- | --- | --- |
| 1 to 2 | IP clarification and user discovery | Written research-use terms for any CH-Predict model specification; open-source licence chosen; 15 to 20 structured interviews with CH trial teams, biobank managers and clinical operations staff |
| 2 to 5 | Clonalyst v0.1 | Python package and local interface; model registry with provenance; yield tracker; audit report; reproduces published All of Us AUCs within 0.01 when run with licensed specifications |
| 4 to 6 | Independent technical testing | External code and security review; tested install in at least one institutional research environment |
| 4 to 9 | Retrospective validation | Comparison with age-only selection per gene; calibration by setting and ancestry group; temporal hold-out in a later All of Us data release |
| 6 | Pilot gate | Ethics approval and laboratory agreement in place, or funds move to the fallback |
| 8 to 14 | Prospective feasibility pilot | 450 samples in three arms (model-guided, age-only, random), confirmatory targeted sequencing, observed against forecast yield |
| 10 to 15 | External user evaluation and release | At least five teams outside the development group run v1.0 on their own data; release notes and adoption plan |

Fallback if the pilot cannot start by month 9: run the same three-arm comparison on a temporal hold-out in a later All of Us release, and use the sequencing budget for a second external validation or extended engineering.
